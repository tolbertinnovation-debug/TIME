# Standard 10-week course template

Every TIME master course uses this layout (Moodle "Topics" format, 11 sections). Instructors fill it in. The Program Coordinator checks it before the first cohort runs.

**Low-bandwidth rules for every lesson**
- Text and PDF first, audio second, video last. Keep videos under 5 minutes and under 15 MB.
- Every lesson has a downloadable PDF, so students can study offline in the Moodle app.
- Live classes are recorded and the recording is posted within 48 hours, along with a one-page summary.
- Quizzes work on a phone: one question per page, no large images.

---

## Section 0 — Week 0: Orientation
- **Welcome** (page): who the instructor is, how to reach them, office hours, the cohort's WhatsApp group link
- **Course outline** (PDF): learning outcomes, weekly topics, assessment weights (below), completion rules
- **How to study on the TIME platform** (page + 2-minute audio): logging in, the Moodle app, downloading for offline use, submitting work
- **Platform check** (quiz, ungraded): 3 questions to confirm the student can open, answer and submit
- **Introduce yourself** (forum)
- **Attendance** (attendance activity): orientation session

## Sections 1–10 — one per week

Each week uses the same pattern:

| Item | Moodle activity | Notes |
|---|---|---|
| Week overview | Label | What you'll learn this week (2–3 outcomes), time needed |
| Lesson | Page or Book | Main teaching content, readable on a phone |
| Lesson notes | File (PDF) | The same content, for offline study |
| Optional media | URL / File | Short audio or video, always with a text alternative |
| Live class | URL (Meet/Zoom) + Attendance | Link and time; recording posted afterwards |
| Discussion | Forum | One prompt; students post once and reply to two classmates |
| Weekly check | Quiz | 5–10 questions, 2 attempts |

**Extra items in particular weeks**

| Week | Extra |
|---|---|
| 3 | **Assignment 1** (or practical activity) |
| 5 | **Midterm examination or assessment** · Mid-course check-in survey (Feedback) |
| 8 | **Assignment 2** (or practical activity) |
| 10 | Review session · **Final exam or course project** · Course evaluation (Feedback) · Certificate (`mod_customcert`, unlocked when the course is completed) |

Payment reminders aren't tied to a course week. The 2nd installment is due 8 weeks after each student's first payment, so Finance tracks it per student (see `lms/README.md`).

Teacher-education courses also have a **Teaching practicum** assignment in week 10. A study centre facilitator or instructor observes a lesson, and the observation form is uploaded as the submission.

## Gradebook

100-point system (decided 31 Oct 2026, pending formal approval). Use Moodle's "Natural" aggregation with these category maximums:

| Category | Points | Contains |
|---|---|---|
| Continuous assessment | 30 | Weekly quizzes, discussions, participation/attendance |
| Assignments & practical activities | 20 | Assignment 1, Assignment 2, lab work or practicum tasks |
| Midterm examination or assessment | 20 | Week 5 midterm |
| Final examination or course project | 30 | Week 10 final |
| **Total** | **100** | |

Set the course total's **grade to pass to 70**.

**Course completion:** a total of at least 70/100, all required assessments completed, course-specific requirements met (e.g. teaching practicum, lab work), and fees cleared. Set these under *Course completion* so the certificate unlocks automatically, and release certificates only after the Coordinator → Dean → Executive Director sign-off.
