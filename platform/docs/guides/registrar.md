# Guide for the registrar

You work from **Administration** in the menu.

## Before each intake

1. **Intakes and study centres:** add the intake and its start date. Add any new study centre.
2. **Classes:** choose the course, the intake, weekdays or Saturdays, and online or blended. A blended class needs a study centre. You can set a number of places.
3. Open the class and assign its lecturer and facilitators under **Lecturer and facilitators**.
4. When everything is ready, open the intake for applications on **Intakes and study centres**.

## Applications and enrolment

- **Approvals** lists every application waiting for you. **Approve** enrols the student and gives them a student number. **Reject** needs a short reason, which the student sees.
- A full class cannot take another student.
- Requests to withdraw or defer arrive in the same inbox.
- A newly enrolled student's class opens when Finance confirms their first payment. That part belongs to Finance.

## Ending a class

When teaching has finished and results are published, open the class and choose **End this class**. Students can request certificates only after this. **Reopen this class** undoes it if it was ended by mistake.

## Certificates

1. A student's certificate request arrives in **Approvals**. Choose **See the student's record before deciding** to see their result, fees and enrolment in one place.
2. If the record is correct, approve it. It then goes to academic leadership, who issue the certificate.
3. **Certificates** lists every certificate issued, with search.
4. **Last number issued on paper:** before the first certificate is issued here, enter the last number TIME issued on paper for each kind (for example TC-001), so that numbering carries on without a gap or a repeat.

## Help desk and sponsors

- **Help desk** shows students' requests about accounts, classes and technical problems. Reply there; the student is notified.
- **Sponsors:** add a sponsor, link their students, and produce a progress report. A student appears in a report only if they have agreed to share their progress.

## What you cannot do

Change roles, confirm payments, approve results or issue certificates. Those belong to administrators, Finance and academic leadership.
